Module GE02-B (Practical): Modern Vector Engines & Desktop GUI

Curriculum Practice Note

Welcome to the practical desktop foundations track! In modern Rust desktop applications, developers rarely manipulate direct software framebuffers (1D byte arrays). Instead, industry standards focus on resolution-independent vector paths, modern event loops, and hardware-accelerated vector rasterization.

This module provides the architectural specifications, types, and traits needed to build a modern desktop engine that seamlessly transitions into Project 02 (Continuous SVG Spaces) and PDF vector export pipelines.

Zero-Panic Norm: Using .unwrap() or .expect() is strictly prohibited. Programs must handle all errors gracefully using pattern matching, Result, and Option types.

Theoretical Foundation: GPU Vector Rendering & Scaling

Modern desktop applications decouple application state from visual rendering through an event-driven loop paired with resolution-independent vector paths. Instead of mapping pixel offsets manually into linear memory arrays, vector paths (such as MoveTo, LineTo, and Curves) are transformed by affine matrices and rendered dynamically at the monitor's physical scale.

[ Vector Geometry (SVG / Path) ] ──► [ Affine Matrix / Transform Pipeline ]

[ OS Window Context (winit) ] ◄── [ Target Surface / Raster Engine ]
